Provider onboarding · administrator

Service-provider product mappings. This is not the field technician's workflow.

Provider mapping import is onboarding work, completed before a survey begins. It is deliberately separated from the field app: a technician has no import controls and never chooses a mapping file. A mapping is a purchasing cross-reference only — it never establishes what is installed on a door.
Session
Not signed in as an administrator
Where the data client is reachable, the signed-in profile's user_type decides, and only admin is accepted. On a local-only device there is no authentication authority, so this step is recorded as a local onboarding session and confined to this device.
Administrator authorization required. Provider mappings are imported during onboarding by an administrator. There is nothing to import from here until that session is established.
The service provider · product mapping import
Import a CSV with manufacturer, product_model and provider_sku. Optional: product_description and configuration_details. A mapping never establishes installed-product identity.
Where the mapping is used
Once imported, the mapping supplies the provider's ordering number beside a reviewed replacement part in the purchasing review. That is the only place the technician sees it, and it changes nothing about how the part was identified.
