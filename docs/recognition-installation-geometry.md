# Installation geometry pilot

The recognition route combines label readings, visual reference comparison and a conservative mounting-pattern check. No marker, printer, field measurement or minimum photo resolution is required. Small photos can still be insufficient evidence; resizing does not recover missing features.

## Comparison and limits

The classifier locates actual body mounting-hole centers and an independently visible rectangular mounting face in the same plane. Its landmarks are observations, not surveyed points. The server rectifies that face and compares the horizontal interval ratios and paired-row arrangement. The first pilot accepts at most 20% relative layout discrepancy; this tolerance is an engineering setting, not a calibrated accuracy probability. No absolute photo length is computed. Face aspect ratio is unknown, so row spacing in inches is reference information only.

Four holes alone are insufficient: a homography can map any nondegenerate four-point quadrilateral onto another. The separate rectangular face supplies the perspective constraint. Hidden holes, curved silhouettes, missing corners, other mounts and mixed planes cause abstention. They do not exclude a product. When landmarks are unavailable, the approved pilot candidate pages are still retrieved for AI comparison of visible body, arm and valve features.

The shared mounting pattern retains LCN 4040XP, LCN 4041 DA and Cal-Royal CR441 together. It never establishes identity, completes an unread label suffix, or authorizes purchasing. It is not an exhaustive closer catalog. Other models can share the pattern. Labels, distinguishing features and technician review remain necessary.

Run evidence contains geometry version, normalized observations, discrepancies, source hashes/pages, candidates and limits. Source PDFs and photos are not committed. Tests exercise perspective, mirroring, ambiguity, invalid/missing landmarks and approval filtering. Neither those tests nor this pilot establish 90% field recognition accuracy; that requires a representative labeled field-photo evaluation.
