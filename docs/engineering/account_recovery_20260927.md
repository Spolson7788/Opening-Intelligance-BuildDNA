A bounded operator-issued recovery flow now lets the account holder choose their password directly. It is enabled only on Netlify site 6430c57d-8a98-43bc-ba25-94007dd244f2 in deploy-preview context. There is no public code issuance endpoint. The authorized operator issues a cryptographically random 256-bit code, stores only its SHA-256 in account_recovery_tokens, binds it to an exact existing user and gives the plaintext code privately to that user. Maximum lifetime is 30 minutes. No code or password belongs in this repository or logs.

The confirmation route binds code plus email, locks the user before locking the code, checks expiry/consumption/active status, stores bcrypt cost-12, increments session_version and consumes all that user's outstanding codes atomically. Role, organization, facility assignments and data are unchanged. New middleware rejects previous session versions. Older immutable deployments do not implement session-version revocation, so this is not a claim that all historical deployment sessions have been invalidated.
